\# Ethanol Basis Map Directory



This folder contains the generated ethanol corn basis maps used by the GitHub Pages site.



\## Scripts Required to Build the Basis Maps



Run these scripts in the following order.



\### 1. Runscrape.py

Pulls and updates ethanol basis data.



\### 2. Contour Map 2025.py

Builds the current ethanol nearby basis map.



\### 3. Contour Map 30 day back.py

Builds the 30-day historical basis map.



\### 4. Contour Map 365 day back.py

Builds the 365-day historical basis map.



\### 5. Basis Change Map.py

Builds the basis change map and largest mover chart.
